# Матрица трассировки. Заказ справки об обучении

Учебный пример к [`case_concept.md`](case_concept.md). Функции здесь ещё верхнего уровня: дробление на «система должна» делает лабораторная 3.

| Цель | Функция концепта | Сценарий | Критерий |
|------|------------------|----------|----------|
| BG-1 Типовая справка без визита | Выдать типовую справку автоматически | UC-1 | Файл в кабинете, визита нет |
| BG-1 | Записать выдачу в журнал | UC-4 | У файла есть запись |
| BG-2 Отказ с причиной | Показать отказ, если студент не числится | UC-2 | Причина видна, файла нет |
| BG-2 | Отклонить заявку вне перечня с причиной | UC-3 | Причина видна после решения секретаря |
| BG-1, граница выпуска | Передать заявку вне перечня секретарю | UC-3 | Военкомат не выдаётся молча |

Вне матрицы сознательно: печать бумаги, правка контингента, визит в деканат как шаг типовой справки. Они перечислены в границах концепции.
